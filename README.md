# 🎁 THE DEAL — الصفقة

## 🎮 نسخة ChatGPT Site المنشورة

**[افتح THE DEAL والعب مع أصحابك](https://the-deal-party.tommyalaraby.chatgpt.site)**

هذه نسخة مستقلة منشورة للعب من الموبايل: اعمل قعدة، شارك كود الغرفة، وابدأوا من 3–10 لاعبين. لا تحتاج إلى بطاقة دفع أو تسجيل داخل اللعبة. تستخدم النسخة قاعدة بيانات خاصة على Sites لحفظ الغرف والمزامنة بين الأجهزة، مع سرية الأشعة والعروض الخاصة وحماية الشراء المتزامن. تظل الغرفة قابلة للاسترجاع عند تحديث الصفحة من نفس المتصفح. اللعبة كلها نقاط افتراضية.

بُنيت هذه النسخة على واجهة وقواعد المستودع عند commit `af92e3e70a992736c1a41ba662a03abab09134bf`، ومصدرها محفوظ في مشروع Sites وإصداراته. نجحت 10 اختبارات للمنطق والحفظ، و18 فحص اتصال فعلي بين ثلاث هويات منفصلة، ومراجعة تصميم بعرض موبايل 390 بكسل.

---

لعبة بارتي عربية مستقلة للموبايل. غرفة بكود، بيع وشراء صناديق غامضة، أشعة سرية، صفقات خاصة، مؤثرات وصوتيات. 3–10 لاعبين (أو وضع تجريبي مع ثلاثة بوتات).

## 🎮 رابط اللعبة بعد تفعيل GitHub Pages

يفترض أن يكون الموقع على: `https://tommyahmrd1.github.io/the-deal-party-game./`.

هذه الصيغة **متوقعة فقط** حتى يتم التأكد من اكتمال النشر. GitHub Pages ينشر ملفات مجلد `public` آلياً بعد أي تعديل على `main` عبر `.github/workflows/pages.yml`.

إذا لم يعمل الرابط بعد رفع الملفات، افتح `Settings → Pages → Build and deployment → Source: GitHub Actions` في هذا المستودع. عندها سيعمل الـworkflow على نشر اللعبة.

## كيف تعمل اللعبة دون سيرفر مدفوع؟

هذه النسخة المخصصة للاستضافة الثابتة على GitHub Pages تستخدم **PeerJS + WebRTC**. موبايل صاحب القعدة يعمل كخادم مؤقت للغرفة، وبيوصل باقي الأجهزة عن طريق اتصال نظير لنظير. الإشارة تتم عبر خدمة PeerJS العامة، وهي خدمة خارجية غير مضمونة الاستمرار أو العمل على كل الشبكات. يستحسن أن يظل صاحب القعدة على صفحة اللعبة وألا يقفلها أو يقفل شاشة موبايله؛ عند خروجه تنتهي الغرفة. قد تمنع بعض الشبكات اتصالات WebRTC.

النسخة الأصلية في `server.js` ما زالت تعمل على Node.js لخادم مستقل عبر `npm start`. ملفات الواجهة الثابتة في `public` تستعمل محرك P2P من `engine-p2p.js`.

## خطوات اللعب

1. افتح رابط اللعبة من موبايلك واضغط **اعمل قعدة**.
2. اكتب اسمك واختار شخصيتك، ثم انسخ رابط القعدة أو كودها.
3. كل صاحب يفتح نفس الرابط، يدخل اسمه ويختار **ادخل بكود**.
4. يبدأ صاحب القعدة اللعبة عندما يدخل 3 لاعبين أو أكثر.
5. في كل جولة صندوق سري لكل لاعب، ويمكنك المزايدة أو البيع أو كشف قيمة صناديقك بفُرصتين أشعة طوال الماتش.
6. أعلى رصيد **نقاط افتراضية** بعد 5 جولات يكسب.
