# 🎁 الصفقة | THE DEAL

لعبة بارتي عربية للموبايل: كل واحد يفتح **نفس الرابط** من تليفونه، يدخل اسمه، ويعمل/يدخل غرفة بكود. الصناديق والمزايدات والمفاوضات كلها بتحصل مباشرة بين اللاعبين. مستقلّة تمامًا عن أي مشروع أو موقع أو قاعدة بيانات أخرى.

## 🚀 شغّلها على رابط عام

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2FTommyahmrd1%2Fthe-deal-party-game.)

1. اضغط **Deploy to Render** فوق وسجّل الدخول إلى حساب Render أو أنشئ حسابًا مجانيًا.
2. وافق على إنشاء خدمة **the-deal-party-game** من ملف `render.yaml`. الإعدادات تطلب خطة **Free** فقط (لا يوجد دفع داخل اللعبة).
3. بعد أن تصبح الخدمة **Live**، انسخ رابطها المنتهي بـ `.onrender.com` وابعته لأصحابك.
4. افتحوا الرابط من موبايلات مختلفة، اختاروا **غرفة جديدة** / **انضم بغرفة**، وابدأوا.

> الاستضافة المجانية تدخل وضع السكون بعد فترة عدم استخدام، وقد تستغرق أول زيارة وقتًا إضافيًا. حالة الغرف محفوظة في ذاكرة السيرفر فقط، وتُفقد إذا أعيد تشغيله أو توقّف. اختاروا غرفة جديدة لو حصل إعادة تشغيل.

لو زر Render لم يفتح صفحة إنشاء الخدمة تلقائيًا، افتح https://dashboard.render.com/ > New > Blueprint، ثم اختار المستودع `Tommyahmrd1/the-deal-party-game.`.

## طريقة اللعب

- **3–10 لاعبين** في الغرفة؛ للتجربة الفردية اضغط «جرّب مع بوتات».
- **5 جولات**؛ كل لاعب يبدأ بـ **1200** نقطة افتراضية و**فُرصتين أشعة** يكشف بهما محتوى صندوقه سرًا.
- كل جولة يستلم اللاعب صندوقًا سريًا. يقدر **يعرضه للبيع بسعر يحدده** أو **يشتري صندوقًا معروضًا** أو **يبعت عرض تفاوض خاص** أو **يكشف قيمة صندوقه** باستخدام الأشعة.
- عند انتهاء الجولة تتفتح الصناديق وتُضاف أو تُخصم قيمتها إلى رصيد مالكها الأخير، ويفوز صاحب أعلى رصيد بعد الجولة الخامسة.
- السعر والفلوس **نقاط داخل اللعبة فقط**، ليست أموالًا حقيقية.

## تشغيل محلي واختبار

مطلوب Node.js 20 أو أحدث:

```sh
npm ci
npm test
npm start
```

افتح http://localhost:3000. للأجهزة على الواي فاي نفسه، افتح عنوان الكمبيوتر المحلي مع المنفذ 3000.

## ملفات المشروع

- `server.js` — السيرفر ونظام الغرف والأسعار والتصويت على الصفقات.
- `lib/realtime.js` — الاتصال المباشر عبر WebSocket.
- `public/` — واجهة الموبايل والحركات والصوتيات.
- `tests/smoke.js` — اختبار الغرف والمفاوضات والشراء والتسوية.
- `render.yaml` — إعداد استضافة Render المجانية.

يمكن استخدام المشروع مستقلاً؛ لا توجد أي مفاتيح خارجية أو قاعدة بيانات أو ارتباط بمشروعات أخرى.
